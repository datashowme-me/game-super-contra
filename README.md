# 魂斗罗: 终极突击 (Super Contra Strike)

> 🎮 经典街机横版射击游戏重制版，采用 React 19 + TypeScript + Vite + Tailwind CSS 构建，集成 **Agent Sprite Forge (v0.4.0)** 16-Bit 高清像素管线与 Web Audio API 8-Bit 芯片音效引擎。支持本地同屏双人合作、自由选关、自动开火与科乐美经典秘籍。

---

## 🌟 核心特色

- **👥 本地同屏双人合作 (2P Co-op)**：
  - 1P 比尔·雷泽 (Bill Rizer，蓝色迷彩) 与 2P 兰斯·比恩 (Lance Bean，红色迷彩) 同屏协同作战。
  - **经典借命系统 (Borrow Life)**：一方命数耗尽阵亡后，按下跳跃或开火键即可向队友借命空降重生！
- **🎯 经典动作与全向射击**：
  - 完整还原 8 方向精准射击（站立正上方、奔跑中 45° 斜射、水平射击、跳跃空中斜下 45° 射击）。
  - 空中蜷身空翻旋转跳跃、趴下匍匐爬行（避开高空子弹与低矮障碍）、下跳半实心跳板（`下 + 跳跃`）、水域潜水隐蔽。
- **🔥 自动开枪模式 (Auto-Fire)**：
  - 默认开启全自动连发，自动朝当前朝向/瞄准方向高频射击，解放双手，畅享扫射割草爽感。
  - 支持按下快捷键 `T` 或点击界面上的火焰按钮随时在「自动开火」与「手动按键」间切换。
- **💥 经典武器弹药库**：
  - **P (Normal)**：标准半自动步枪 / 快速点射。
  - **M (Machine Gun)**：加特林连续扫射重机枪。
  - **S (Spread Gun)**：五向扇形扩散高爆散弹枪，全屏压制。
  - **L (Laser Gun)**：高穿透性光束激光，可贯穿多个敌兵与多节装甲。
  - **F (Flame Gun)**：双重旋转爆炸火球枪，范围杀伤。
  - **B (Barrier)**：10 秒无敌能量护盾球，免疫触碰与子弹伤害。
  - **1UP**：额外增加 1 条作战生命。
- **🗺️ 三大战役战区与巨型多阶段 BOSS**：
  - **Stage 1: 密林瀑布 (Jungle Outpost)** -> 突破热带丛林与瀑布水域，迎战关底**基地防御壁垒 (Wall Fortress)** 双炮台与红色核心。
  - **Stage 2: 机械要塞 (Iron Base)** -> 突入重工工业基地与传送带陷阱，对决**泰坦机械巨蛛 (Titan Mech Spider)**。
  - **Stage 3: 异形巢穴 (Alien Hive)** -> 深入跳动生物腔体与异形胞囊，决战**异形首脑心脏 (Giga Alien Heart/Brain)**。
- **⭐ 科乐美 30 条命秘籍 (Konami Code)**：
  - 标题画面输入 `↑ ↑ ↓ ↓ ← → ← → B A`，或直接点击界面黄色星标即可一键激活 30 条命！
- **🔊 纯 Web Audio 8-Bit 芯片合成器**：
  - 无需加载庞大的外部音频文件，实时纯代码算法生成各关卡热血 8-Bit 芯片 BGM、枪炮声、弹跳声、跳伞声与爆炸声。
- **📱 双端全兼容**：
  - 完美支持桌面键鼠，并内置可随时一键隐藏/显示的屏幕虚拟摇杆与触控按键。

## 🚀 本地运行与开发指南

### 1. 环境准备

请确保你的本地环境已安装：
- **Node.js**：`>= 18.0.0` (推荐 Node 20 LTS 或 Node 22)
- **包管理器**：`npm` (或 `pnpm` / `yarn`)

### 2. 克隆项目与安装依赖

```bash
# 1. 克隆你的 GitHub 仓库
git clone <YOUR_GITHUB_REPO_URL>
cd contra-strike

# 2. 安装项目依赖
npm install
```

### 3. 启动本地开发服务

```bash
npm run dev
```

启动成功后，浏览器访问：
```text
http://localhost:3000
```
*(默认运行在 3000 端口，可通过浏览器立即体验！)*

### 4. 生产环境构建与打包

```bash
# 构建生产环境静态资源 (输出至 dist 目录)
npm run build

# 本地预览生产构建产物
npm run preview
```

## 🎮 操作控制速查表

### 1P 单人模式（双重键位全面兼容）

| 动作 | 推荐按键 (WASD) | 备选方向键 | 鼠标操作 |
| :--- | :--- | :--- | :--- |
| **移动 / 瞄准** | `W` (上) / `S` (下) / `A` (左) / `D` (右) | `↑` / `↓` / `←` / `→` | - |
| **跳跃 / 翻滚** | `空格键 (Space)` / `K` 键 / `X` 键 | - | - |
| **开火射击** | `J` 键 / `Z` 键 / `F` 键 / `Enter` | `小键盘 0 / 1` | **鼠标左键点击/拖拽瞄准** |
| **下跳半实心板** | `S + 空格` / `S + K` | `↓ + 空格` | - |
| **自动开火开关** | `T` 键 (一键开启/关闭自动射击) | - | 点击屏幕上方火焰胶囊 |
| **全屏战术轰炸** | `L` 键 / `C` 键 / `Shift` 键 | - | - |

### 2P 双人同屏合作模式

| 角色 | 移动与瞄准 | 跳跃 / 翻滚 | 射击 / 连发 | 战术轰炸 |
| :--- | :--- | :--- | :--- | :--- |
| **1P 比尔 (左侧键盘)** | `W` `A` `S` `D` | `K` / `空格` | `J` / `Z` | `L` |
| **2P 兰斯 (右侧键盘)** | `↑` `←` `↓` `→` | `小键盘 2` / `I` | `小键盘 1` / `U` | `小键盘 3` / `O` |

> 💡 **提示**：2P 模式下，当某位特种兵生命耗尽（Lives: 0）阵亡时，连按 **跳跃键** 或 **射击键** 即可自动借取队友生命重生！

## 📁 项目结构导览

```text
├── src/
│   ├── assets/              # 高清街机原画与实景视差背景素材
│   │   └── images/          # 密林、基地、异形背景及 BOSS 原画
│   ├── components/          # React UI 交互组件
│   │   ├── HeaderBar.tsx    # 顶部导航、快速选关、音效控制、自动开火状态
│   │   ├── TitleScreen.tsx  # 主菜单（1P/2P 切换、难度、秘籍开关）
│   │   ├── LevelSelectModal.tsx # 3 大独立战区关卡选择弹窗
│   │   ├── ControlsModal.tsx    # 键盘按键与操作指南
│   │   ├── MobileControls.tsx   # 屏幕触控与鼠标虚拟手柄
│   │   ├── GameOverModal.tsx    # 战败结算与重试
│   │   └── StageClearModal.tsx  # 关卡通关与军衔晋升
│   ├── game/                # 游戏核心逻辑引擎
│   │   ├── SpriteForge.ts   # 16-Bit 高清动作绘制管线与背景预载
│   │   ├── audio.ts         # Web Audio API 芯片音效合成器 (BGM+SFX)
│   │   ├── bosses.ts        # 关底 BOSS 行为树与多阶段 AI
│   │   ├── engine.ts        # 物理碰撞、弹道、按键捕获、借命与游戏主循环
│   │   ├── levels.ts        # 关卡地图数据（地形、水域、敌军生成点）
│   │   ├── renderer.ts      # 60FPS Canvas 渲染器与视口等比自适应
│   │   └── types.ts         # TypeScript 类型定义
│   ├── App.tsx              # 主应用入口，全局事件监听与焦点管理
│   ├── index.css            # 全局样式与 Tailwind CSS 配置
│   └── main.tsx             # React 根节点挂载
├── package.json             # 项目依赖与运行脚本
└── vite.config.ts           # Vite 构建配置
```

## 🛠️ 技术栈

- **框架与视图**：React 19, TypeScript
- **构建工具**：Vite 8
- **样式方案**：Tailwind CSS v4
- **音频系统**：Web Audio API (Procedural Synthesizer, 0 外部音频体积)
- **图形管线**：HTML5 Canvas 2D + Agent Sprite Forge (v0.4.0)
- **图标系统**：Lucide React
